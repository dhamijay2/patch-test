# Multiple Patch Sets Selection - User Guide

## How to Select Multiple Patch Sets

### On Windows/Linux:
1. **Single Click** - Click a series name to select it (single selection)
2. **Hold Ctrl + Click** - Hold Ctrl and click on multiple series to select them all
3. **Hold Shift + Click** - Hold Shift and click to select a range of series

### On Mac:
1. **Single Click** - Click a series name to select it (single selection)
2. **Hold Cmd + Click** - Hold Cmd and click on multiple series to select them all
3. **Hold Shift + Click** - Hold Shift and click to select a range of series

## What Happens When You Select Multiple Series?

When you select multiple patch test series:
- ✅ All allergens from all selected series are combined
- ✅ Allergens are automatically checked/selected
- ✅ Duplicate allergens (appearing in multiple series) appear only once
- ✅ Allergens are sorted by location number in the Generated Patch Test
- ✅ The Collate Handouts feature works with all selected allergens

## Example Workflow

1. **Select multiple series**: Hold Ctrl and click on "80 Series", "60 Series", and "90 Series"
2. **See combined allergens**: The allergen list now shows allergens from all three series
3. **Manually adjust if needed**: Uncheck any allergen you don't want to test
4. **Generate patch test**: The patch test now includes allergens from all selected series
5. **Collate handouts**: Click "Collate Handouts" to create a merged PDF with handouts for all positive allergens

## Tips & Tricks

- **Clear selection**: Click the "-- View All / Custom --" option or select nothing to see all allergens
- **Mix and match**: You can manually check/uncheck allergens even after selecting series
- **Check your selection**: Selected series will appear highlighted in the dropdown
- **Save sessions**: Use "Save Session" to remember your multi-series selection for later

## Visual Indication

When multiple series are selected, the dropdown will show:
- All selected series names highlighted
- A taller dropdown box to accommodate multiple selections
- The selected series will remain visible

## Troubleshooting

**Q: I selected multiple series but I don't see many allergens**
- A: Check the search bar - it might be filtering results. Clear the search to see all allergens.

**Q: Some allergens appear in multiple series - will they be duplicated?**
- A: No! The system automatically removes duplicates. Each allergen appears only once.

**Q: Can I still use the single-series selection?**
- A: Yes! Just click one series or use "-- View All / Custom --" as before.
